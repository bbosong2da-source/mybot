# ☁️ 구름 언덕과 까마귀 정원 봇 (v2)

할 일 · 루틴 · 관리자 공지를 관리하는 텔레그램 봇입니다.
개인방과 그룹 토픽에서 모두 쓸 수 있고, 방(토픽)마다 데이터가 따로 저장됩니다.

## 배포 순서

1. **기존 봇 데이터 백업**
   Supabase → Table Editor → `bot_data` → Export to CSV
2. **테이블 만들기**
   Supabase → SQL Editor에 `schema.sql` 전체를 붙여넣고 Run, 이어서 `schema_quiz.sql`, `schema_recite.sql`, `schema_recite_exam.sql`도 Run
3. **환경변수 설정** (호스팅 서비스의 Environment 설정)

   | 이름 | 값 |
   |---|---|
   | `BOT_TOKEN` | 텔레그램 봇 토큰 (기존과 같음) |
   | `SUPABASE_URL` | Supabase 프로젝트 URL (기존과 같음) |
   | `SUPABASE_KEY` | ⚠️ **비밀 키**: `sb_secret_...`(Secret key) 또는 `eyJ...`(service_role) |
   | `ADMIN_ID` | 관리자 텔레그램 숫자 ID (생략하면 75036448) |

   `schema.sql`은 보안을 위해 RLS를 켭니다. 그래서 공개용 **anon 키로는 동작하지 않습니다.**
   service_role 키는 서버 환경변수에만 넣고, 다른 곳에 공유하지 마세요.
4. **기존 봇 중지 → 새 봇 배포**
   같은 토큰으로 봇 두 개가 동시에 돌면 `Conflict` 오류가 납니다.
   - 시작 명령: `python main.py`
   - 설치: `pip install -r requirements.txt`
5. 2주쯤 문제없이 쓰면 SQL Editor에서 `drop table bot_data;`로 기존 테이블을 정리합니다.

## 사용법 요약

| 입력 | 동작 |
|---|---|
| 그냥 입력 | 할 일 추가 (한 줄에 하나, `[카테고리]` 줄 지원) |
| `내일 보고서` `금 발표` `다음주 월 회의` `11/20 발표` `3일 후 제출` `일요일 장보기` | 날짜 지정 |
| `!10/20 비율 계산` | 날짜로 해석하지 않음 |

| `/r` / `/r 월수금 운동` | 루틴 관리 / 추가 (`매일` `평일` `주말` `화요일` 지원) |
| `/w` | 주간 리포트 (일~토) |
| `/t 22:30` / `/t off` | 밤 점검 시각 / 끄기 |
| `/q` / `/q 9-18` / `/q off` | 성구 퀴즈 출제 시간 보기 / 바꾸기 / 끄기 |

| `질문: 내용` | 관리자에게 질문 전달 |
| `/bc` `/bcr` `/re 번호 내용` | 관리자: 공지 과제 · 결과 · 답변 |

## 📜 성구 퀴즈

**관리자가 성구 올리기:** 봇과의 개인 대화방에 `.txt` 파일을 보내거나 `/qa` 다음 줄부터 붙여넣습니다.
```
요 3:16 / 하나님이 세상을 사랑하사 독생자를 주심 / 하나님이 세상을 이처럼 사랑하사…
시 23:1 / 여호와는 나의 목자 / 여호와는 나의 목자시니 내게 부족함이 없으리로다
빌 4:13 / 능력 주시는 자 안에서 모든 것을 할 수 있음
```
- 순서: 주소 / 핵심 내용 / 전체 본문(선택). `/`는 처음 두 개까지만 칸 나누기로 씁니다.
- 새로 올리면 기존 구절에 **추가**되고, 같은 주소는 새 내용으로 바뀝니다. `#`으로 시작하는 줄은 무시합니다.
- `/qv` 목록, `/qd 요 3:16` 삭제

**출제:**
- 방마다 정한 시간대(기본 13~22시)에 매시 정각 4지선다 1문제가 나옵니다.
- 문제 유형은 두 가지가 무작위로 섞입니다: 주소 → 핵심 내용, 내용 → 주소.
- 구절이 4개 이상일 때부터 출제됩니다.
- 틀린 구절은 그 방에서 더 자주 나옵니다. 통계는 표시하지 않습니다.
- 놓친 문제는 그날 자정까지 풀 수 있습니다.
- `/l`과 밤 점검에 `📜 성구 퀴즈 3/10`이 루틴처럼 표시되고, 그날 문제를 모두 풀면 🍋 완료와 🔥 연속 기록이 쌓입니다.

## 📖 계시록 전문 암송

**관리자가 본문 올리기:** 봇에게 `.txt` 파일을 보낼 때 **설명 칸에 `암송`**이라고 적거나, `/rva` 다음 줄부터 붙여넣습니다.
```
계 1:1 / 예수 그리스도의 계시라 이는 하나님이 그에게 주사 …
계 1:2 / 요한은 하나님의 말씀과 예수 그리스도의 증거 …
```
- `/`는 없어도 되고, 책 이름을 빼고 `1:1 본문`만 써도 됩니다.
- 장·절 순서대로 정렬하고, 같은 절은 새 본문으로 바뀝니다(진도는 유지).
- `/rvs`로 방별 진도를 확인합니다.

**사용자:** `/rv`로 시작하고 하루 새 구절 수(1·2·3절)를 고릅니다. 원하는 사람만 참여합니다.
- 카드 시간대(기본 **18~22시**)에 그날 카드를 골고루 나눠 보냅니다. 한 시간에 메시지 하나이고, 그 안에서 카드를 넘깁니다.
- 새 구절은 전문 → 빈칸(세 단어 중 하나) → 더 넓은 빈칸(세 단어 중 둘) → 주소만 보고 떠올리기 4단계로 익힙니다.
- 복습 카드는 두 종류입니다: 주소 보고 암송하기, 앞 구절 보고 이어 말하기.
- 채점은 스스로(완벽 / 조금 틀림 / 못 외움) 하거나, **⌨️ 타이핑**(봇 메시지에 답장)으로 합니다.
  - 타이핑은 띄어쓰기·문장부호를 무시합니다.
  - 틀리거나 빠진 단어가 없어야 완벽, 정확도 80% 이상이면 조금 틀림입니다.
- 간격 복습: 완벽 1→3→7→15→30→60일, 조금 틀림은 간격 유지, 못 외움은 다음 날 다시. 하루 복습은 최대 15개입니다.
- 진도는 실제로 익힌 만큼만 나갑니다.
- `/l`과 밤 점검에 `📖 계시록 암송 n/m`이 루틴처럼 표시됩니다(🍋, 🔥).
- `/rv` 진도판에서 장별 진도(✉️ 📜 ✅ 🏅), 예상 완료일, 하루 개수 변경, 쉬기를 할 수 있습니다.
- `/rv 19-22` 시간 변경, `/rv off`·`/rv on` 쉬기·다시 시작
- 자정이 지나도 다음 날 새벽 4시 전까지는 그날 카드로 인정합니다.

**⏭ 바로 시험보기:** 새 구절 카드 첫 화면에서 4단계를 건너뛰고 바로 시험을 볼 수 있습니다. 처음부터 완벽이면 이미 아는 구절로 보고 **7일 뒤** 복습합니다.

**📝 장별 시험** (`/rv 시험`, `/rv 시험 3`, 진도판의 버튼): 고른 장을 1절부터 순서대로 주소를 보고 암송합니다. 결과는 진도에 바로 반영됩니다(배치고사).
- 아직 안 외운 절: 완벽이면 외운 구절로 등록(7일 뒤 복습), 조금 틀림이면 다음 날 복습, 못 외움이면 등록하지 않음(나중에 새 구절 카드로 차근차근)
- 이미 외운 절: 평소 복습처럼 간격 조정
- 새 구절 카드는 **아직 안 외운 절 중 가장 앞 절**부터 나오므로, 시험으로 외운 장은 건너뜁니다.
- 완벽 90% 이상이면 그 장에 🏅. 중간에 멈추면 다음에 이어서 봅니다.

**⭐ 북마크** (`/rv 북마크`, 진도판의 버튼):
- 정답 화면의 ☆로 직접 북마크하고, '못 외움'이 2번 쌓이면 자동으로 북마크됩니다.
- 북마크한 구절은 복습 간격이 최대 3일이고 복습 목록에서 먼저 나옵니다.
- 3번 연속 완벽이면 자동으로 해제됩니다. "북마크만 시험"도 볼 수 있습니다.

**타이핑 채점:** 답을 보내면 "답장으로 입력해 주세요" 안내 메시지를 지워서, 답장 상태가 계속 남지 않습니다.

**본문 고치기 (관리자만):** `/rva` 다음 줄에 고친 절만 보내면 됩니다. 예: `계 19:12 / 그 눈이 …`. 진도와 복습 기록은 그대로입니다.

## 하루 흐름 (한국 시간, 자정 기준)

- **00:00** 날짜가 바뀝니다. 별도 작업 없이 날짜로 계산됩니다.
  - 못 끝낸 할 일은 자동으로 `🔥D+1`이 됩니다.
  - 루틴은 요일에 맞춰 나타납니다.
- **08:00** 아침 알림 (할 일이나 루틴이 있는 방만)
- **설정한 시각(기본 22:00)** 밤 점검: 남은 할 일마다 ✅ 완료 · ➡️ 내일로 · 🗑 삭제
- **토요일 밤 점검** 주간 리포트도 함께 보냅니다. 밤 점검을 끈 방에는 토요일 22:00에 보냅니다.
- **자정이 지나도 다음 날 새벽 4시 전까지는** 밤 점검 메시지의 버튼(✅ 완료, 루틴 체크, ➡️ 내일로, 🗑 삭제)과 성구 퀴즈 답을 **그날 기록으로** 처리합니다.
  - 새벽 4시가 지나면 "지난 밤 점검이에요"로 안내합니다.
  - `/l` 목록의 버튼은 누른 날 기준입니다.
  - 밤 점검 시각을 `/t 00:30`처럼 정해도 전날 밤 점검으로 보냅니다.

## 폴더 구조

```
main.py          실행 · 핸들러 등록 · 정해진 시각 작업 · 헬스체크 서버
schema.sql       Supabase 테이블
bot/config.py    환경변수, 상수
bot/dates.py     날짜 계산, '날짜 + 할 일' 해석, 루틴 요일 해석
bot/logic.py     연속 기록, 오늘 목록·주간 통계 계산 (순수 함수)
bot/storage.py   Supabase 저장소 / 메모리 저장소
bot/views.py     메시지 텍스트와 버튼
bot/handlers.py  사용자 명령어, 일반 메시지
bot/callbacks.py 버튼 처리
bot/admin.py     관리자 기능
bot/jobs.py      아침 알림, 밤 점검, 주간 리포트, 퀴즈 출제 호출
bot/quiz.py      성구 퀴즈 순수 로직 (파일 해석, 출제, 진행 상황)
bot/quiz_handlers.py  /q /qa /qv /qd, .txt 업로드, 답 버튼, 정각 출제
schema_quiz.sql  성구 퀴즈 테이블 (기존 프로젝트에 추가 실행)
bot/recite.py    계시록 암송 순수 로직 (본문 해석, 빈칸, 간격 복습, 타이핑 채점)
bot/recite_handlers.py  /rv /rva /rvs, 카드 버튼, 타이핑 답장, 시간대 발송
schema_recite.sql  계시록 암송 테이블 (기존 프로젝트에 추가 실행)
bot/recite_exam.py  장별 시험(배치고사)·북마크
schema_recite_exam.sql  장별 시험·북마크 테이블 (기존 프로젝트에 추가 실행)
tests/           테스트 (pip install pytest pytest-asyncio 후 pytest)
```

Supabase 환경변수 없이 실행하면 메모리 저장소로 돌아갑니다(재시작하면 데이터가 사라짐).
테스트용 봇 토큰으로 기능을 먼저 확인해 볼 때 유용합니다.
